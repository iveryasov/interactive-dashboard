# ⚡️ Interactive CRM Dashboard

A modern, responsive Single Page Application (SPA) dashboard built with Vanilla JavaScript and CSS Grid. Designed for real-time order tracking, business metrics visualization, and state management.

## 🚀 Key Features

*   **Dynamic SPA Navigation:** Tab switching engine without page reloads using event delegation and dataset attributes.
*   **Order Management Engine:** Real-time order creation and deletion with dynamic DOM rendering.
*   **Theme Switcher (Dark / Light Mode):** Persistent theme toggle using CSS Custom Properties and `localStorage`.
*   **Zero External UI Frameworks:** Built entirely with pure semantic HTML5, modern CSS Grid/Flexbox, and native ES6+ JavaScript.

## 🛠️ Tech Stack

*   **Logic:** JavaScript (ES6+, DOM API, Event Delegation, LocalStorage)
*   **Structure:** Semantic HTML5 (`<aside>`, `<header>`, `<main>`, `<section>`)
*   **Styling:** CSS3 (Grid, Flexbox, CSS Variables)

## 📦 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. No build tools or dependencies required.
